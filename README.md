# 📊 Superstore Sales Analysis Dashboard

## 📌 Project Overview

An interactive Excel dashboard designed to analyze Superstore sales performance and generate meaningful business insights.

This project focuses on understanding sales, profitability, regional performance, and product categories using Microsoft Excel.

## 🛠️ Tools & Technologies

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Excel Formulas
- Data Analysis

## 📈 Project Features

- Sales Performance Analysis
- Regional Sales Analysis
- Category Analysis
- Product Analysis
- KPI Tracking
- Interactive Dashboard
- Dynamic Filtering Using Slicers

## 📁 Project Files

| File | Description |
|---|---|
| `superstore_sales_dashboard.xlsx` | Main Excel dashboard workbook |

## 🚀 How to Use

1. Download the Excel workbook.
2. Open it using Microsoft Excel.
3. Explore the different analysis worksheets.
4. Use interactive slicers to filter the dashboard.
5. Analyze sales and profitability trends.

## 🎯 Project Objective

The objective of this project is to demonstrate practical skills in data cleaning, data analysis, business intelligence, and interactive dashboard development using Microsoft Excel.
